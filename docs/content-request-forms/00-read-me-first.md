# Content request — read me first

What we need from AB Tours to build the website, and how to send it.

#### How to fill this form

- Write in the yellow column. Where the prototype text is shown as “Now”, write “Keep” if it is fine, or give your new text.

- For photos and videos, write the file name in the yellow column and send the files in one folder named after this form (for example “02 Homepage”).

- Sizes are recommended minimums. Larger originals are better; we resize and compress them for the website.

- Only send photos and videos you own or have permission to use. Please add the photographer’s name if a credit is needed.

- If something is not ready, leave it blank and tell us when it will be available.

Please return by: 27 November 2026

### How to send

- Fill the yellow column in each form. Where text is marked “Now”, write “Keep” or your new text.

- Put photos and videos in one folder per form, named like the form (for example “04 Emirate Pages”), and share the folders by Google Drive, Dropbox or WeTransfer.

- Name each file so we can match it to the form, for example “Dubai - cover photo.jpg”.

- Recommended sizes: cover photos at least 2400 × 1350 px; card photos at least 1600 × 1200 px; videos MP4, 1920 × 1080, 10–20 seconds; logos SVG or transparent PNG.

- Only send photos, videos and logos you own or have permission to use.

Please return all forms by: 27 November 2026

### Decisions we need from you

- Include Ajman as an emirate page: yes or no.

- Destinations for each international holiday style, and the cruise routes.

- The final .ae domain name.

- Arabic version of the website: at launch or later.

- UAE tourism licence numbers to show on the site.

- Reply time promise and the email addresses that receive each type of enquiry.
