# Attraction tickets

The Attraction Tickets page. Tickets are arranged on request; there is no online checkout.

#### How to fill this form

- Write in the yellow column. Where the prototype text is shown as “Now”, write “Keep” if it is fine, or give your new text.

- For photos and videos, write the file name in the yellow column and send the files in one folder named after this form (for example “02 Homepage”).

- Sizes are recommended minimums. Larger originals are better; we resize and compress them for the website.

- Only send photos and videos you own or have permission to use. Please add the photographer’s name if a credit is needed.

- If something is not ready, leave it blank and tell us when it will be available.

Please return by: 27 November 2026
